## Publication-state note

The immutable machine baseline was generated with `run_purpose="test"` from a
draft manuscript. The human review is complete, but this example is not claimed
to be the final manuscript-bound publication-gated matrix.

`publication_gate.json` is included deliberately so this state is transparent.
A future final manuscript publication run should use
`DFFP_RUN_PURPOSE=publication` and the genuinely frozen source manuscript.
